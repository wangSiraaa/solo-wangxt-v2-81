# 水库供水教学模拟系统

面向课堂的水库水量平衡模拟：学员逐个时段回答“**水从哪里来、到哪里去**”，
再比较不同供水方案。**本系统仅用于教学，不连接真实闸门，不替代现实供水决策。**

## 架构

| 层 | 技术 | 职责 |
|---|---|---|
| 模拟引擎 | Python + SciPy | 固定时间步水量平衡；库容曲线插值（`scipy.interpolate`） |
| 后端 API | FastAPI | 场景校验、单位换算、模拟、两方案对比 |
| 数据库 | PostgreSQL | 保存场景定义（JSONB） |
| 前端 | Angular | 场景编辑、库容/取水/缺口图表、逐时段水量平衡表、方案对比 |

## 快速开始

### 方式一：Docker（后端 + PostgreSQL）

```bash
docker compose up --build        # 后端 http://localhost:8000
cd frontend && npm install && npm start   # 前端 http://localhost:4200
```

### 方式二：本地分别启动

```bash
# 数据库（或设置 DATABASE_URL 指向已有 PostgreSQL）
docker compose up db

# 后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload     # http://localhost:8000/docs 可查看 API

# 前端
cd frontend
npm install
npm start                         # http://localhost:4200
```

无 PostgreSQL 时也可临时用 SQLite 体验：
`DATABASE_URL=sqlite:///./dev.db uvicorn app.main:app`

## 水量平衡模型（每个时段 Δt）

```
S(t+1) = S(t) + I(t)·Δt − E(t) − R(t)·Δt − Spill(t)·Δt
```

- **I(t)** 入流；**E(t)** 蒸发 = 蒸发水深 × 水面面积（面积随库容由库容曲线插值）
- **R(t)** 放水 = 最小生态流量 + 两类用水取水（按用户设定的优先级先后分配）
- **Spill(t)** 弃水：库容超过上限时的泄放（教学模型，不模拟闸门能力）
- **水位** 由库容按给定库容曲线换算（线性插值）

**硬条件**：库容上下限、最小生态流量。当硬条件互相冲突（如来水不足以同时
满足生态流量与库容下限），该时段被明确标记为**冲突时段**并给出原因，
系统绝不静默伪造可行解。

**缺测来水**：该时段所有结果显示为“缺失”（前端断线/空行），**绝不按 0 处理**；
下一时段从最后已知库容继续，并标记“起始库容为估计值”。

## 输入单位

流量：`m3/s`、`L/s`、`m3/h`、`万m3/d`；库容：`m3`、`万m3`、`百万m3`；
蒸发：`mm/step`、`mm/d`。所有输入先换算为 SI 再计算，不同单位表示的同一
物理过程结果完全一致（有测试保证）。

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/simulate` | 运行场景（不保存），返回逐时段结果与守恒校验 |
| POST | `/api/scenarios` | 保存场景到 PostgreSQL |
| GET | `/api/scenarios` / `/{id}` | 列表 / 读取 |
| POST | `/api/scenarios/{id}/run` | 运行已保存场景 |
| POST | `/api/compare` | 对比两方案（传 id 或内联定义），返回差异指标 |

## 测试：逐时段水量守恒核对

```bash
cd backend && python3 -m pytest tests/ -v
```

覆盖题目要求的三类样例，每个时段独立重算守恒残差（容差 1e-6 m³）：

- **零来水**：库容不变 / 每步减少量恰等于放水体积 / 蒸发损失恰等于水深×面积
- **超库容洪峰**：出现弃水、库容永不超过上限、总量闭合（末库容 = 初始 + 入流 − 弃水）
- **不同单位输入**：同一过程用 `m3/s` 与 `m3/h + 万m3 + mm/d` 输入，结果逐时段一致

另有：缺测显示为缺失而非零、生态流量硬约束、优先级分配顺序、
冲突时段精确定位、库容曲线水位换算、API 端到端（保存→运行→对比）。

## 教学建议用法

1. 在“场景设置”页载入示例（30 天：洪峰→干旱→一个缺测点），运行模拟；
2. 在“模拟结果”页逐时段查看：水从入流来，到蒸发、生态下泄、取水、弃水去，
   每行“守恒残差”都应接近 0；观察缺测时段的“缺失”显示与冲突时段的红色标记；
3. 修改两类用水的优先级，分别保存为两个场景；
4. 在“方案对比”页比较两方案的缺口、弃水与冲突时段差异。
